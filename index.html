FixMod Privacy Policy

Last updated: 2026-10-13

Data Collection

FixMod does NOT collect, transmit, or sell any personal data to external servers.

The extension reads order information (status, device model, IMEI, diagnoses, resolutions) from the user's own Fixably account page and stores it locally in:

  • chrome.storage.local
  • IndexedDB
  • JSON backups in the user's Downloads folder (FixModDB)

Data Usage

All data is used exclusively for displaying personal statistics (order counts, status distribution, daily repair trends) within the extension.

Data Sharing

No data is shared with third parties. No analytics, no tracking, no advertising.

Remote Code

FixMod does not use remote code. All JavaScript is bundled inside the extension package.
